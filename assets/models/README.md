# Strike 3D Asset Directory

Place your downloaded 3D model `.glb` files from Meshy.ai (or Blender / Sketchfab) into this directory.

### Supported Model File Names:

#### Buildings:
- `hq.glb` - Command Center
- `barracks.glb` - Tactical Barracks
- `gatling.glb` - Gatling Laser Turret
- `cannon.glb` - Plasma Cannon
- `mine.glb` - Credit Refinery
- `plasma.glb` - Plasma Synthesizer
- `lab.glb` - Laboratory Tech Center
- `clan.glb` - Clan Station Hub
- `builder.glb` - Builder Drone Hut
- `tesla.glb` - Hidden Tesla Coil
- `mine_trap.glb` - Proximity Landmine
- `wall.glb` - Barrier Wall

#### Units & Heroes:
- `hero.glb` - Strike Commander Hero Mech
- `enforcer.glb` - Cyber Enforcer Infantry
- `juggernaut.glb` - Heavy Juggernaut
- `spectre.glb` - Railgun Spectre
- `drone.glb` - Hover Drone Striker

---

If a `.glb` asset file is present in this directory, the game automatically renders the Meshy 3D model! If a file is missing, the game seamlessly falls back to high-quality procedural 3D texturing.
